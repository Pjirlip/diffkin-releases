# Security policy

Please report vulnerabilities privately through GitHub's private vulnerability reporting on this repository (*Security → Report a vulnerability*), not through a public issue. Include the Diffkin version and build (Settings → About), the operating system and the steps to reproduce; never include credentials, license keys or personal data.

Reports are acknowledged as soon as possible. Fixes ship as signed releases through the normal update channel; the release notes state when a release contains a security fix.

What Diffkin does to keep your data safe is described in [Security and privacy](docs/user/security.md).
